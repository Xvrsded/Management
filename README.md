# RT/RW Management — Project scaffold

Initial Next.js App Router + TypeScript + TailwindCSS scaffold for an RT/RW management app.

Features included in scaffold:
- App Router layouts and route groups
- TailwindCSS global styles
- Supabase client placeholder
- Zustand auth store skeleton
- React Query provider skeleton
- Basic responsive dashboard shell and navigation
- PWA manifest placeholder

Run locally:

```bash
npm install
npm run dev
```
